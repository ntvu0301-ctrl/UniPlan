# UniPlan

A single-file, front-end study-planner prototype. The interface, styles, and JavaScript are all in `index.html`.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Notes

- The included courses and schedule are sample data; this project does not connect to a real university system.
- Embedded account seeds were removed and sample email addresses were replaced with `example.com` placeholders. Use the sign-up flow for a local demo account.
- Authentication is client-side demo behavior, not production security. Do not enter real passwords or sensitive student information.
